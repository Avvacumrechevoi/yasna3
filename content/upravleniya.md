# Управления «Золотого Ясеня» — данные для интеграции

Файл рядом: [`upravleniya.json`](upravleniya.json). Это двенадцать
управлений центра в одном месте: имя, темы, описание, руководитель,
формат, эмблема, страница, контакты, ссылка на запись. Собрано из
разметки сайта zolotoj-yasen.ru; при расхождении прав сайт.

Прямые адреса для приложения:

- JSON: `https://raw.githubusercontent.com/Avvacumrechevoi/yasna3/main/content/upravleniya.json`
- эмблемы: `https://raw.githubusercontent.com/Avvacumrechevoi/yasna3/main/src/img/<файл>` — поле `emblema.v_repozitorii`
  (или с сайта — `emblema.na_sajte`; из-за границы сайт может не открываться, зеркало —
  `http://zolotoj-yasen.ru.website.yandexcloud.net/`)
- страницы управлений: `https://zolotoj-yasen.ru/upravleniya/<id>/` — исходники в папке `upravleniya/`

## Поля записи

| поле | что это |
|---|---|
| `nomer` | порядковый номер 1–12, в этом порядке управления показаны на сайте |
| `id` | латинский слаг; совпадает с папкой страницы и с параметром `?dir=` на записи |
| `nazvanie` | имя по-русски, как на сайте — менять и транслитерировать нельзя |
| `temy` | 1–2 короткие темы для плашек |
| `opisanie` | одно-два предложения для карточки |
| `rukovoditel` | ФИО руководителя управления |
| `format` | города и онлайн |
| `emblema` | файл, адрес на сайте, адрес в репозитории |
| `zayavka` | ссылка на форму записи с предвыбранным управлением; `null` там, где в форме нет своего варианта |
| `stranica` | страница управления на сайте; `null`, если страницы нет (тогда ведём на `zayavka`) |
| `kontakty` | каналы и почта самого управления; общие телефоны центра — в блоке `centr` |

## Правила, которые держит сайт

- Подразделения называются **«управления»**. Слова «направления», «отделы», «секции» не используются.
- Названия только по-русски: **Гербальдика**, **ЛитПроСвет**, **Ясна-Школа**.
- Эмблемы принадлежат управлениям: показывать как есть, на светлой подложке, без перекраски и обрезки.
  Пять из них растровые с непрозрачным фоном (`alexandria-emblem.jpg` и др.) — на тёмном фоне нужен светлый диск.
- Почта `proyasna@yandex.ru` относится только к управлению «Воспитание и Образование».
- Числа, даты, обещания — только те, что уже есть на сайте.

## Событие

Блок `sobytie`: съезд «Большой лист» 26 сентября 2026, 16:00–20:00, Москва.
Точного адреса зала на сайте нет — «пришлём после регистрации». Запись:
`https://zolotoj-yasen.ru/zayavka/?goal=day`.

## Как обновлять

JSON собран скриптом из `index.html` (карточки `.kard`) и `upravleniya/*/index.html`.
Если на сайте что-то поменялось — пересобрать тем же способом или поправить руками
и записать дату в `obnovleno`.
