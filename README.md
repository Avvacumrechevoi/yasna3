# Золотой Ясень

Открытое сообщество исследователей русского языка, истории и культуры.

**Прод:** https://zolotoj-yasen.ru/

> ⚠️ **Сайт живёт НЕ на GitHub Pages** (с 19.08.2026). Файлы лежат в Яндекс
> Object Storage, перед ними CDN Яндекса, домен делегирован в Яндекс Облако.
> GitHub Pages остался запасной площадкой и держится свежим. Подробности —
> раздел «Где всё лежит».

> **Адреса страниц** (05.08.2026): управления живут по `/upravleniya/<слаг>/`,
> заявка — `/zayavka/`. Прежние `/1/pages/*.html` оставлены заглушками
> с переадресацией — удалять нельзя, по ним ходят старые ссылки.
> Пути к файлам на этих страницах **абсолютные** (`/1/src/...`): относительные
> сломались бы при переносе.

> ⚠️ **Папку `1/` удалять нельзя ни при каких обстоятельствах.** Название
> обманывает: это не архив. В ней лежат ВСЕ стили, шрифты, картинки и видео
> живого сайта — 149 МБ из 151. Удаление обрушит сайт целиком.

## Две версии сайта

| Версия | Ссылка | Что это |
|---|---|---|
| **новый визуал** | https://zolotoj-yasen.ru/ | **основной сайт**: лежит прямо в корне (`index.html` + `src/`) |
| **прежняя** | https://zolotoj-yasen.ru/1/ | предыдущий дизайн, сохранён целиком в `1/` |

Новый визуал живёт в КОРНЕ, чтобы адрес был просто `zolotoj-yasen.ru` без
префикса: GitHub Pages не умеет подменять пути, поэтому корневой файл должен
физически быть этой версией. Прежний адрес `/2/` оставлен редиректом на корень —
ранее разосланные ссылки не ломаются.

Версии дорабатываются независимо по вёрстке и стилям. Не забывайте: общие
страницы управлений лежат в `upravleniya/<слаг>/index.html` и тянут стили из `1/src/` — то есть
`1/src/styles.css` и `refresh.css` обслуживают ЖИВОЙ сайт, а не только архив,
и трогать их надо с оглядкой. **Общие только внутренние страницы** — заявка и страницы
управлений лежат в `upravleniya/` и используются обеими версиями, поэтому форма
правится в одном месте. Их ссылки «на главную» ведут на корень (живой сайт).

Чтобы вернуть прежний дизайн основным — поменять содержимое корневого
`index.html` на редирект `./1/index.html` (как было до 25.07.2026) либо
поменять файлы местами. Откат к состоянию до появления второй версии — тег
`version-1`.

## Как добавить новое управление (чек-лист)

> Основной сайт — корневой `index.html`. Карточки управлений там —
> **статическая вёрстка** в `#dirGrid`: `<a class="card">` с `.idx`, `.mono`,
> `.tag`, `h3`, `p` и `.foot`. Скрипт-сборщик удалён 08.2026: без выполнения
> JavaScript поисковик не видел ни описаний управлений, ни ответов — треть
> текста главной. Не возвращайте его.
> Кольцо медальонов в блоке «26 сентября» — отдельный массив `reelItems`,
> синхронизируйте вручную.

1. **Логотип** → `src/img/<имя>.png` для основного сайта (512×512, прозрачный
   фон, если эмблема). Если нужен и в прежней версии — копия в `1/src/img/`.
2. **Карточка на основном сайте** (`index.html`): добавьте объект в массив
   `var dirs=[…]` — поля `n` (номер), `img` или `m` (буква), `tag`, `h`, `p`,
   `lead`, `loc`, `url` (если есть страница). Разметка карточки и ссылка в
   футере строятся автоматически. **Отдельно** правится массив `reelItems`
   (кольцо из 9 медальонов в блоке «26 сентября») — он свой, синхронизируйте
   вручную, иначе в кольце останется старый набор.
   Число «девять» в заголовке секции и в тексте лида — вёрсткой, тоже вручную.
   **В прежней версии** (`1/index.html`, блок `#directions`) — вёрсткой:
   скопируйте существующую `<a class="dir">` (активная, со ссылкой) или
   `<div class="dir is-soon">` (статус «формируется»). Виды логотипа в карточке:
   - `.dir-glyph has-logo` — квадратная эмблема (Неглинка, Граника);
   - `.dir-glyph has-wordmark` + класс `is-wordmark` на карточке — словесный
     логотип, скрывает дублирующий текст-заголовок (ЛитПроСвет);
   - `.dir-glyph has-tile` — цветная плашка-бейдж (Ясна-Школа);
   - `.dir-glyph` + `<span>Б</span>` — буквенный глиф, если логотипа нет.
3. **Страница** → скопируйте `upravleniya/granika/index.html` (простая) или
   `alexandria.html` (с фото-галереей и видео) и наполните. Страницы собраны
   из готовых классов — inline-стили не нужны:
   - `.fmt-grid / .fmt-num / .fmt-title / .fmt-desc` — «Чем занимаемся»;
   - `.about-body / .about-text / .mission-box / .mission-text /
     .label-accent / .label-muted / .unique-text` — «О управлении»;
   - `.join-body / .join-step / .join-num / .join-title / .join-desc /
     .join-cta` — «Как присоединиться»;
   - `.kv-list / .kv-row / .kv-val / .kv-line` — панель «Формат»;
   - `.photo-grid` — галерея фото; `.video-box` — блок с вертикальным видео;
   - `.voice / .voice-by` — отзывы; `.coord` — люди.
4. **Перелинковка**: футеры всех страниц + related-блоки (`.rel-grid`) +
   счётчик управлений в текстах главной («девять» → обновить) + FAQ.
5. **Медиа**: фото ужимайте до ≤1200px по длинной стороне (jpeg q≈82);
   видео — H.264/AAC, вертикаль 540×960 достаточно, файл держите ≤ 20 МБ.

## Где всё лежит

| Звено | Где | Заметка |
|---|---|---|
| файлы сайта | Яндекс Object Storage, бакет `zolotoj-yasen.ru` | включён хостинг сайта, `index.html` / `404.html` |
| раздача | CDN Яндекса, ресурс `bc8rscsoctj24nzj4dym` | кэш 120 с на узле, 60 с в браузере |
| сертификат | Certificate Manager, `yasna-site` | Let's Encrypt, продлевается сам по записям в зоне |
| домен | Яндекс Облако, зона `yasna` | `ANAME` в корне на CDN; делегирование у reg.ru |
| запасная площадка | GitHub Pages | свежая копия; возврат — правкой делегирования у reg.ru |

**Почему переехали.** GitHub Pages (адреса `185.199.108–111.153`) фильтровался
из московских сетей: 17.08.2026 сайт для Москвы почти сутки не открывался,
а реклама всё это время работала. Аудитория и Директ у нас Москва, поэтому
это были прямые потери.

**Чего стоит опасаться.** Домен, CDN, хранилище и сертификат теперь у одного
поставщика. Запасная площадка есть, но переключиться на неё можно только
через DNS, который живёт там же. Если понадобится аварийный возврат —
менять делегирование в панели reg.ru обратно на `ns1/ns2.reg.ru`.

## Деплой

Пуш в `main` → GitHub Actions «Deploy to GitHub Pages» (~1–2 мин) выкладывает
**в оба места**: в Object Storage (боевое) и на Pages (запас).

- Ключ выкладки — служебного аккаунта `yasna-deploy`, единственная роль
  `storage.editor`. Лежит в секретах репозитория: `YC_S3_KEY_ID`, `YC_S3_SECRET`.
- **Типы файлов задаются явно** отдельным проходом. Хранилище само их не
  проставляет: `.css` уезжает как `text/plain`, и браузер такие стили просто
  не применяет — сайт открывается голым текстом. Не убирайте этот шаг.
- Правка видна на сайте через пару минут (кэш CDN). Чистки по кнопке нет.
- Статус: вкладка **Actions**. Упал — откройте ран → **Re-run failed jobs**.

**Отправка в репозиторий — по SSH** (`git@github.com:…`). Токены больше
не нужны и заводить их для этого не надо.

## Наблюдение

Сборка «Сайт недоступен?» проверяет сайт каждые 20 минут (по факту GitHub
запускает через 30–45 — расписание у него неточное):

- прямой запрос главной;
- **замер с узлов в России** — решающий: обычные сервисы наблюдения ходят
  из Европы и московскую поломку 17.08 не заметили бы;
- срок сертификата.

Тревога поднимается, только если молчит вся Россия, больше половины узлов
мира, сертификату меньше 14 дней или **замер из России не удалось сделать
вовсе** (слепой монитор опаснее отсутствующего). Упавшая сборка → письмо
владельцу репозитория, тема письма — имя сборки.

## Афиша событий

Данные — `content/events.json` (в витрину не выкладывается). Два скрипта:

```bash
python3 tools/events/sobrat.py --file "Афиша Ясны — события.xlsx"   # таблица → json
python3 tools/events/stranicy.py                                    # json → страницы
```

`stranicy.py` собирает `/sobytiya/` и вставляет блок на главную **между
метками** `АФИША:НАЧАЛО` и `АФИША:КОНЕЦ` — руками этот блок не правьте,
перезапишется.

Вторая фаза (общая таблица руководителей как источник) написана и проверена,
но не подключена: нужна публичная ссылка на файл в Яндекс Диске.

## Локальный запуск

```bash
python3 -m http.server 8000   # из КОРНЯ репозитория
# http://localhost:8000/     — основной сайт
# http://localhost:8000/1/   — прежняя версия
# запуск из каталога 1/ покажет прежнюю версию и сломает ссылки «/»
```

`file://` не подходит: `cross.js` монтируется в `#cross-mount` (диаграмма).

Шрифты **свои**, в `src/fonts/` — Google Fonts не используются (README до
20.08.2026 утверждал обратное). При загрузке главной браузер делает ровно
один внешний запрос — счётчик Метрики. Это специально: сайт должен
открываться, когда половина интернета недоступна.
