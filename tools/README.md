# Служебные скрипты

## `muzyka.py` — фонограмма для роликов «Ясных маршрутов»

Музыка в роликах на `upravleniya/marshruty/` написана этим скриптом и
синтезируется целиком из синусоид: ничего заимствованного в ней нет,
вопрос прав на фонограмму снят.

Исходные ролики пришли со своей звуковой дорожкой неизвестного
происхождения — она выброшена и заменена этой.

Запуск:

```
python3 tools/muzyka.py <длительность в секундах> <зерно> <файл.wav>
```

Зерно задаёт мелодическую линию: у каждого ролика своё, поэтому тринадцать
роликов не звучат одинаково, но остаются одной музыкой. Нужен только `numpy`.

Устройство: ля минор натуральный, темп 62, ход Am7 — Fmaj7 — Cmaj9 — Em7
намеренно без доминантового разрешения, чтобы музыка не тянула внимание
на себя под видеорядом. Три голоса — колокольчик, подложка, бас;
реверберация свёрткой с синтезированным импульсным откликом.

## `oblozhka-lid.html` — лид на обложке репоста

`src/img/og-cover.jpg` рисовалась в canvas, и текст на ней живёт в пикселях:
мета-теги его не правят. Когда меняется число управлений, лид надо
перенабрать.

Порядок: взять чистую обложку из коммита `0dc94a1` (в более поздних лид уже
перенабран), стереть три строки лида переносом фона снизу с подгонкой
уровня по колонкам, открыть эту страницу локальным сервером рядом с
`og-ref.png` (чистый оригинал) и `og-bg.png` (со стёртым лидом).

Параметры набора восстановлены перебором по среднеквадратичному отклонению
от оригинала и менять их не нужно: **Arial 19.5px, трекинг 0.28px, x = 70,
базовые линии 390 / 419 / 448, цвет rgb(120,107,88)**. Контроль — две
неизменные строки: отклонение ~27 и ~15, правый край первой строки 585
при 582 в оригинале, вне лида ноль отличающихся пикселей.

Набирать надо все три строки сразу. Одна строка, вставленная между двумя
чужими, выбивается по рисунку букв — это видно и на замере, и глазом.
