Сайт «Золотого Ясеня» — https://zolotoj-yasen.ru/. Статические HTML-файлы,
без сервера и фреймворка. Рабочая копия: `/Users/avva/yasna-work/yasna3`.

**Сначала прочитай [ARCHITECTURE.md](ARCHITECTURE.md)** — там устройство,
все настройки Яндекс Облака, аварийные сценарии и восстановление с нуля.
[README.md](README.md) — как править сайт: классы вёрстки, чек-листы.

## Правила, которые клиент устанавливал явно

Нарушение любого из них — переделка.

- **Запрещена конструкция «не X, а Y».** Формулировать утвердительно.
- Подразделения называются **«управления»**, никогда не «направления».
- **Не публиковать непроверяемое.** Числа, даты, обещания — только если
  подтверждены. Лучше промолчать, чем написать правдоподобное.
- Не поднимать формулировкой мысль, которой у читателя не было
  («дресс-кода нет» вместо тона дня — так делать нельзя).
- Авторские тексты клиента правятся **только по типографике**.
- Продукт говорит **от себя**: без «по книге», «слова автора», сносок на автора.

## Ловушки, которые уже стоили времени

**Проверять сайт из этой среды нельзя.** Она ходит через прокси, который
разрешает имена сам и игнорирует `--resolve` и подмену `Host`. Проверка
«CDN отдаёт 200» на деле измеряла GitHub. Мерить только снаружи —
`check-host.net` (`check-http`, `check-tcp`, `check-dns`), с заголовком
`User-Agent`, иначе служба отвечает отказом.

**Сайт открывается из России и может не открываться из-за границы.** Узел
CDN отвечает `ERR_CONNECTION_REFUSED` некоторым зарубежным сетям. Если сайт
«не открывается» — сперва спроси, откуда. Для просмотра из-за границы:
`http://zolotoj-yasen.ru.website.yandexcloud.net/`.

**`grep` врёт на кириллице** в этой среде. Русские строки искать питоном.

**Папку `1/` удалять нельзя.** Название выглядит как архив, а внутри все
стили, шрифты и картинки живого сайта — 149 МБ из 151.

**Всё, что кладётся в корень, становится страницей сайта.** Трижды утекало:
материалы рекламы с промокодом, настройки среды, документация. Исключения
живут в `.github/workflows/deploy.yml`. После правки — проверить, что
служебные адреса отдают 404.

**Главная — отдельный сайт.** У неё 43 КиБ своих стилей и нет общих
компонентов (`.panel`, `.ev`). Блок, свёрстанный на них, выйдет голым
текстом. На главной есть `.card`, `.way`, `.btn-pri`, `.btn-sec`, `.ar`.

**Токены в переписке не нужны.** Отправка по SSH, ключ на машине.

## Как проверять правки

Замерами, а не на глаз: `getBoundingClientRect`, вычисленные стили,
`curl` по боевым адресам. Проверять 1280 и 375 пикселей — клиент замечает
мобильную вёрстку.

Сборка выкладывает в оба места (Object Storage и GitHub Pages) сама,
пуш в `main` по SSH. Правка видна через пару минут.

Афиша событий собирается генератором:

```bash
python3 tools/events/stranicy.py     # content/events.json → /sobytiya/ + блок на главной
```

Блок на главной стоит между метками `АФИША:НАЧАЛО` и `АФИША:КОНЕЦ` —
руками не править, перезапишется.

## Что сейчас не закрыто

- **У 11 событий из 12 нет времени начала.** В афише вместо часа стоит
  «уточняйте по телефону». Ждём от клиента.
- **Расхождение по сбору 26 сентября:** сайт говорит 12:00–16:00 и Колонный
  зал на Большой Никитской; в черновике объявления клиента — 14:00–17:00
  и «адрес уточняется». Не рассылать, пока не сойдётся.
- **Вторая фаза афиши** (общая таблица руководителей как источник) написана
  и проверена, но не подключена: нужна публичная ссылка на файл.
- **Запасной выход из облака.** Домен, CDN, хранилище и сертификат — всё
  у Яндекса. Вернуться на GitHub Pages можно только через DNS, который там же.
- **Директ.** Кампания работала, пока сайт не открывался из Москвы.
  Проверить списания за те дни клиент пока не просил.
